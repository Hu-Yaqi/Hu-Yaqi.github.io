# hu-yaqi.github.io

Personal site of Yaqi Hu. Plain HTML and one stylesheet, no build step.

- `index.html`: home (bio, and the `recent` paragraph to edit as projects move)
- `research.html`: one `<article class="entry">` per project
- `cv.html`: mirrors the LaTeX CV
- `style.css`: shared layout and type
- `assets/yaqi-hu.jpg`: photo

To update: edit the file, then `git add -A && git commit -m "update" && git push`.
